# Atom Constitution
Version: 1.0.0 | Ratified/amended: 2026-09-30

## Principles
Spec Kit governs specification, design, tasks, debugging, evidence and progress. Never label partial files, simulated output or untested work accepted. Runs require bounded lifetimes and durable terminal outcomes. Preserve locked Pi source and user work. Never commit secrets.

## Delivery gates
Backend tests, frontend build, runtime integration, fault injection and live model/browser acceptance are separate evidence. Failed gates remain open. Back up production before deploying a traceable revision; document rollback.

## Governance
Update version and rationale for amendments. Spec/plan/tasks templates reviewed and compatible. Preserve unrelated user edits.
