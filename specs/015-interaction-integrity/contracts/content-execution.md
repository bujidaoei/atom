# Generated content execution contract

Static generated apps may execute same-origin and inline scripts, styles and local client-side form submit handlers. The browser may perform native validation. JavaScript cancels form default navigation when handling application state. Native form transport is forbidden to both same-origin and external targets, including GET/POST, requestSubmit and targeted frames. Network API access, workers, objects and base overrides remain forbidden.

Public and verifier documents reject embedding; owner preview permits only the configured console ancestor. Owner/race embedding sandbox permits scripts, same-origin local storage and local form events. Existing authorization and isolated project origins are unchanged.

Acceptance flows fill all required prerequisites, click the actual primary control and assert an observable resulting state. Future contracts cover each primary mutation; keyboard outcomes cannot substitute for a failing mouse action.
