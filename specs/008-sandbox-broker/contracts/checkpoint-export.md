# Quiescent verified export

Trusted lifecycle export verifies the current grant and serializes against file operations, transitions ready→quiescing durably, then runs a fixed nonroot helper in the inspected live worker. File dispatch is forbidden in quiescing. The helper locks /workspace, applies a 20-second alarm and exports the existing ATOMSNAP1 format to stdout; broker process IO has a 25-second deadline and maximum 64 MiB content + 1 MiB manifest + 14 framing bytes. Independent attempt TTL remains in force.

The broker verifies manifest policy, every file digest, framing and EOF in memory using the same snapshot parser. This does not write a host workspace or leave temporary artifact directories after a crash. Return a verified export containing attempt ID/version, revision and bounded bytes only after rechecking current grant, quiescing state and version. A quiescing attempt may safely repeat export while its grant remains current; this performs no workspace mutation and must yield identical bytes while only the fixed files-v1 helpers are authorized.

An export is not a durable output artifact or registered project revision. Keep state quiescing, never checkpointed, until later trusted control-plane storage and fenced registration succeed. Process death or expiry can lose an in-memory export; recovery retires the worker and preserves previously registered project state. Do not introduce an implicit registration callback or expose an incomplete acceptance endpoint. Full registration, HTTP transfer, runtime completion ordering and production selection remain T009/T008 work.

Helper/verification/late authorization uncertainty retires the attempt and lowers readiness. No partially verified bytes escape as a successful result. Read-only re-export is allowed after a lost response, but state/version/fence/revocation must be rechecked. Tests must demonstrate actual edited container bytes, quiescing exclusion, exact reimport, large output, invalid contents, late revocation and process death without falsely recording checkpointed or a registered revision.
