To run the private broker, provision a service-private existing directory and independently generated secrets outside the repository. Supply ATOM_BROKER_REGISTRY_PATH (absolute database path), ATOM_BROKER_IMAGE (already-local sha256 content ID), ATOM_BROKER_ADMIN_TOKEN and ATOM_BROKER_GRANT_KEY. Optional ATOM_BROKER_SWEEP_SECONDS defaults to 5 (1…60), ATOM_BROKER_BATCH_SIZE to 100 (1…1000), ATOM_BROKER_PORT to 8766 (1024…65535). From backend, run the environment's Python with `-m app.sandbox`. It listens only on 127.0.0.1, one worker, no proxy-header trust/access logs. Environment configuration rejects reuse of API/session/runtime/model credentials when those variables are present, but does not discover other processes' secrets. Deployment must enforce independent secret generation, private directory ACLs and TLS if external routing is later introduced. No dotenv fallback and no runtime selection change.
