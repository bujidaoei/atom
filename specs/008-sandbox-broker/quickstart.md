Child 006/007 results are prerequisites, not substitutes. Record failures and unexecuted gates in evidence.md.

No mocked database can close T003.

Driver acceptance: set ATOM_TEST_DOCKER_IMAGE to an already-local sha256 image ID, run backend/tests/integration/test_sandbox_driver.py, then clear it. Tests must remove only their registry-owned containers in finally blocks and confirm removal. Unit subprocess tests must force actual output overflow and process timeout. Ordinary backend regression skips Docker integration unless explicitly configured; report those skips.

Lifecycle tests: run backend/tests/integration/test_sandbox_lifecycle.py with Docker opt-in, and backend/tests/test_sandbox_lifecycle_lock.py on Windows and Linux. Assert duplicate provisioning does not create twice, revoke intent survives unavailable daemon, broker process exit releases lease and restart retires previous attempt, lost create response produces confirmed cleanup, and expiry cleanup preserves peer. Orphan cases must prove failed observation prevents deletion, failed confirmation leaves a durable pending record, actual process exit after deletion is recoverable, and contradictory ownership is not removed. Registry tests must verify v1→v2 preserves identity/attempts/heads/revocations and a failed migration rolls back DDL/version. T006 still needs service scheduling and in-flight file-operation integration before acceptance.
